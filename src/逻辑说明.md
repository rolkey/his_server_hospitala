# 手术安排窗口 (w_ss_gxmk_ssap) 逻辑说明

## 一、模块概述


| 项目      | 说明                              |
| ------- | ------------------------------- |
| **窗口**  | `w_ss_gxmk_ssap`（继承 `w_master`） |
| **用途**  | 手术安排通知单：查看 / 新增 / 修改 / 急诊手术安排   |
| **主数据** | 手术安排表 `SM_SSAP`，手术申请表 `SM_SSSQ` |


---

## 二、运行模式（由 wf_init 根据参数决定）


| 模式    | 参数              | 标题        | 行为概要                                    |
| ----- | --------------- | --------- | --------------------------------------- |
| **0** | LongParm[1]="0" | 查看手术安排通知单 | 只读，隐藏录入区（住院号/床号、连续录入、作废）                |
| **1** | LongParm[1]="1" | 手术安排      | 新增：若 LongParm[6]>0 则从源单复制后编辑，否则先输住院号再填单 |
| **2** | LongParm[1]="2" | 修改手术安排通知单 | 按 LongParm[6]=ssbh 检索 SM_SSAP 后编辑       |
| **3** | LongParm[1]="3" | 急诊手术安排    | 急诊标志=1，隐藏作废，锁定急诊标志列，先输住院号               |

## 三、核心流程

### 1. 打开窗口 (open → wf_init)

```
open
  → 取 Message.PowerObjectParm 到 istru_Exchange、istr_brxx
  → post wf_init()
wf_init
  → ldbl_ssbh = LongParm[6]（手术编号，查看/修改时用）
  → 根据 LongParm[1] 分支：0 查看 / 1 新增 / 2 修改 / 3 急诊
  → 模式 1/2/3：dw_1.InsertRow(0) 或 从 SM_SSAP 检索
  → 模式 1 且 ll_row>0：wf_copy_source(ldbl_ssbh) 从申请单复制到安排单
  → 检索不到数据则提示并 CloseWithReturn(This,0)
```

### 2. 按住院号/床号带出病人（新增/急诊时）

```
em_srdm.modified（输入住院号或 .床号）
  → 若已有未保存修改，提示是否保存
  → 以 "." 开头：按床号查 ZY_CWSZ 得 ZYH；否则按住院号查 ZY_BRRY 得 ZYH
  → ZYH>0：wf_ssbr(ldbl_zyh)；否则提示不存在
wf_ssbr(adbl_zyh)
  → 用 d_ss_gxmk_sssq_ssbr 检索病人
  → 取申请单号、病人信息、科室等填到 dw_1 第 1 行，手术相关先置空
  → 若有 il_ssks 则写手术科室；急诊时 jzbz=1
```

### 3. 选择手术 (ue_getitem01)

```
从 uo_1 多选控件取选择
  → 若选中且 ssnm>0：从 GY_SSDM 取 SSMC，写入 dw_1 的 ssnm、ssmc，焦点到 ssys
  → 否则清空 ssnm、ssmc，焦点到 ssmc
```

### 4. 保存 (cb_save.clicked → wf_save)

```
wf_save
  ① AcceptText，校验：手术日期≥通知日期
  ② 必填：主治/手术医师、手术名称（ssdm/ssmc）
  ③ ssbh=0（新增）：
       - 取 SM_SSAP 最大编号赋 ssbh
       - 若有 sqdh：UPDATE SM_SSSQ SET APBZ=1
       - 无 sqdh：wf_fill_sssq() 往 SM_SSSQ 插一条并回写 sqdh
       - ii_ReturnValue=1
  ④ ssbh>0（修改）：
       - 若 zfbz=1（作废）：UPDATE SM_SSSQ SET APBZ=0；ii_ReturnValue=3
       - 否则 ii_ReturnValue=2
  ⑤ dw_1.Update()，提交事务，清空修改标志，禁用保存按钮
  失败则回滚，is_error 记错，返回 False
保存成功后
  - 若勾选“连续录入”：清空 dw_1、重置为可输住院号，焦点回 em_srdm
  - 否则仅保存不关窗（关闭逻辑在 closequery）
```

### 5. 从申请单复制到安排单 (wf_copy_source)

```
按申请单号 as_sqdh 用 d_ss_gxmk_sssq 检索
  → 将申请单病人、手术、科室、手术日期等拷贝到 dw_1 第 1 行
  → ssbh=0，各标志位（急诊、会诊、麻醉、手术、作废等）置 0，操作员为当前用户
```

### 6. 无申请单_fill_sssq)时补写申请单 (wf

```
取 SM_SSSQ 最大单号，用当前 dw_1 的 zyh、sqks、ssks、ssnm、麻醉、医师、日期等
写入 SM_SSSQ（当前代码里 INSERT 被注释，仅做事务框架和 sqdh 回写）
```

## 四、数据与校验

### 主要实例变量


| 变量             | 含义                                |
| -------------- | --------------------------------- |
| ib_RowModified | 当前安排单是否有未保存修改                     |
| ib_jzss        | 是否急诊手术                            |
| ib_zfbz        | 当前是否“作废”状态                        |
| il_ssks        | 手术科室（手术系统传入）                      |
| ii_ReturnValue | 关闭窗口返回值：0 异常，1 新增保存，2 修改保存，3 作废保存 |


### 保存前校验

- 手术日期 ≥ 通知日期（安排日期）
- 手术医师：ssys 或 ssys_2 至少一个非空
- 手术名称：ssdm/ssmc 非空

### 作废 (cb_blankout)

- 若当前为“作废”：检查是否已有会诊/谈话/麻醉/器械/手术/费用/术后等记录，有则不允许作废
- 切换 zfbz（0/1），按钮文字在“作废”与“取消作废”间切换，保存时同步 SM_SSSQ.APBZ

## 五、控件与事件要点


| 控件          | 作用                                   |
| ----------- | ------------------------------------ |
| em_srdm     | 住院号或“.+床号”，modified 触发病人带出           |
| dw_1        | 安排单主数据，itemchanged 做日期/手术名称/医师等校验与选择 |
| uo_1        | 手术选择（GY_SSDM），选择结果在 ue_getitem01 回填  |
| cb_save     | 保存，成功后按“连续录入”决定是否清空继续录               |
| cb_close    | 关闭并返回 ii_ReturnValue                 |
| cb_blankout | 作废/取消作废                              |
| cb_copy     | 复制到手术要求(ssyq)或注意事项(zysx)             |
| cb_print    | 打印设置并打印 dw_1                         |


### dw_1 关键事件

- **itemchanged**：检查病人是否已带出；aprq/ssrq 不能无效且通知日期≤手术日期；ssmc 触发手术选择列表；医师/护士列弹出人员选择（w_public_select）
- **itemerror**：aprq/ssrq 根据 ib_bz 决定接受或拒绝
- **closequery**：若有未保存修改，提示保存或放弃，选保存则调 wf_save 后关窗

## 六、表与数据对象


| 对象                  | 说明                         |
| ------------------- | -------------------------- |
| SM_SSAP             | 手术安排表（主维护对象）               |
| SM_SSSQ             | 手术申请表，APBZ=1 表示已安排，作废时改回 0 |
| GY_SSDM             | 手术字典（手术名称、编码）              |
| GY_YGDM             | 员工（医师、护士）                  |
| d_ss_gxmk_ssap      | 安排单 DataWindow             |
| d_ss_gxmk_sssq_ssbr | 按住院号取病人+申请信息               |
| d_ss_gxmk_sssq      | 按申请单号取申请单                  |

## 七、简要流程图

```
[打开] → wf_init 按模式分支
         → 查看(0)：只读
         → 新增(1)：空单 或 从申请单复制
         → 修改(2)：按 ssbh 检索
         → 急诊(3)：空单 + 住院号录入

[录入] → 住院号/床号(em_srdm) → wf_ssbr → 带出病人
       → 手术名称 → uo_1 选择 → ue_getitem01 回填
       → 医师/护士 → itemchanged 弹人员选择

[保存] → wf_save：校验 → 新增则取 ssbh、写/更新 SSQSQ → dw_1.Update
       → 成功且连续录入则清空继续

[关闭] → closequery 提示保存 → cb_close 返回 ii_ReturnValue
```
