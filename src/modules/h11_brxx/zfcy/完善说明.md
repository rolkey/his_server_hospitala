### 2. 字符串拆分功能

**原PB代码逻辑**:
```powerbuilder
// PowerBuilder使用f_string_fz函数将逗号分隔的字符串拆分成数组
f_string_fz(',', gs_cxsz.hlfylbid, gs_cxsz.hl[]) //化验费用类别
```

**实现的TypeScript逻辑**:
```typescript
// 创建拆分和过滤函数
const splitAndFilter = (str: string): string[] => {
  if (!str || str.trim() === '') return [];
  return str.split(',').map(s => s.trim()).filter(s => s !== '');
};

// 使用示例
const hl = splitAndFilter(hlfylbid); // "08,09" -> ["08", "09"]
const bc = splitAndFilter(bcfylbid); // "10" -> ["10"]
```

## 常见问题

### Q1: 为什么参数代码是40而不是13?
A: 根据原PB代码,费用类别参数属于系统标识40的参数组

### Q2: 如何确定费用类别ID?
A: 查询h00_fylb表获取所有费用类别及其ID

### Q3: 可以动态添加新的费用类别吗?
A: 可以,在系统参数表中添加相应参数即可,代码会自动获取

### Q4: 为什么要合并所有费用类别?
A: 简化SQL查询,使用一个IN子句替代多个OR条件,提高性能
