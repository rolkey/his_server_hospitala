## 🔴 Critical — 安全 / 稳定性（应优先修复）

### 1. 密码明文存储与比对

**位置:** `auth.service.ts`
**现状:** bcryptjs 已安装，`compareSync` 已 import，但被注释掉。实际走 `password == user.pwrd.trim()` 明文比对，数据库存储明文密码。
**风险:** 数据库泄露 = 所有用户密码泄露。
**方案:** 启用 `compareSync`；存量密码一次性哈希迁移。

### 2. 关键操作无审计日志

**位置:** `h11_brxx.service.ts`
- L1049 作废出院 — `// TODO: 写入日志（需要实现日志服务）`
- L1249 办理转科 — 同上

**风险:** 医疗合规要求出院/转科必须有可追溯操作记录。
**方案:** 实现审计日志服务（可基于 DB 表）。

### 3. 零测试覆盖

**现状:** Jest v29、@nestjs/testing、supertest 已安装，但全项目 0 个 `*.spec.ts`。89 个模块无任何测试，jsdoc/README 中无任何测试指引。
**方案:** 优先为核心模块补测试：`auth` → `h11_brxx` → `h12_yzzb`。

### 4. 65 处 console.log 在生产运行

**分布:** 26 个文件。最严重：`h12_yzxb.service_new.ts`(12)、`h13_yzzxcs.service.ts`(8)。
**风险:** 日志无分级无结构化，可能泄露患者数据/Token。
**方案:** NestJS 内置 `Logger` 已可用，无需新依赖。`new Logger(this.constructor.name)` 一行替换。

### 5. 生产环境 DB_LOGGING=all

**位置:** `shared.module.ts:40` — `logging: 'all'`
**风险:** 每个 SQL 查询完整输出到生产日志，严重影响性能、淹没日志。

## 🟡 Info — 不规范 / 不一致

### 18. 零宽字符目录名

**位置:** `src/modules/​​h13_yzzxcs​​/` — 目录名前后各有一个 U+200B 零宽空格。
`app.module.ts:40` 的 import 路径也带这两个字符。**不能直接 rename**，必须同时改目录名和所有 import 路径。

### 19. 孤儿目录

**位置:** `src/modules/h13_yzzxcs_delete/` — 未在任何地方 import，应删除。

`h13_yzzxcs`(零宽字符版)、`h13_yzzxcs_tf`、`h13_yzzxcs_delete` — 三份共存。哪份是真正在用的？

`snake_case`（h11_brxx）和 `kebab-case`（sm-ssap, n04-23）共存。同一领域也不一致：`n04_22` vs `n04-23`。部分模块用 PascalCase（`H11JszbModule`），大部分用小写。无迁移计划。

| `src/constants/advice.contants.ts` | 文件名应拼为 `constants` |
| `src/constants/redis.contant.ts` | 文件名应拼为 `constant` |
| `src/constants/` vs `src/common/constants/` | 两套 constants 目录并存，内容不同 |

### 23. h12_xmzd 模块文件名不匹配目录

目录名 `h12_xmzd/`，但内部文件叫 `sfxm.*`（收费项目），与目录名不一致。

### 24. h23 处方模块未分类

`h23_cfmx`、`h23_cfxb`、`h23_cfzb` 三个处方模块在模块树中位置模糊，与 h12/h13 医嘱模块关系不清晰。

### 25. README 与实际不符

- 写 MySQL，实际 MSSQL
- 命令中有 `rm -rf node_modules apps/*/node_modules packages/*/node_modules` — 项目非 monorepo，无 apps/ 和 packages/ 目录
- 代码生成命令用 `-e mysql`，应为 `-e mssql`

### 26. PowerBuilder 源码混在 TypeScript 源码树

- `src/逻辑` — PB 源码 1495 行，手术排班窗口 `w_ss_gxmk_ssap`
- `src/逻辑说明.md` — 业务说明文档
- `src/modules/h11_brxx/brzk/` — PB 源码 408 行
- `src/modules/h11_brxx/zfcy/` — 转科说明 3 个 md 文件

这些不是可执行的 TypeScript，容易误操作，建议移到 `docs/legacy/`。

### 27. tsconfig 过于宽松

`strictNullChecks: false`、`noImplicitAny: false` — 关闭了 TypeScript 最重要的安全检查。

### 28. 部署文件散落根目录

`his-server.service`（systemd unit）、`pm2.json`（PM2 配置）放在根目录，应归入 `deploy/` 或 `ops/`。

### 29. 无 .editorconfig

编辑器设置未标准化（有 `.vscode/settings.json` 但仅限 VSCode 用户）。
